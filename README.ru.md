# slatefree

**Синхронизация многокамерной съёмки мероприятия по одной непрерывной записи рекордера — без хлопушки и генератора таймкода.**
Перетащите папку съёмки на `slatefree.exe`, импортируйте результат в DaVinci Resolve — все клипы на своих местах.
Windows · macOS · Linux

## Зачем

На свадьбах, конференциях и корпоративах камеры весь вечер включаются и выключаются — десятки и сотни коротких клипов
на камеру, — а рекордер (Zoom H4n и подобные) пишет всё мероприятие целиком. Синхронизировать это вручную или
программами, которые сравнивают каждый клип с каждым, долго и ненадёжно: музыка, шум зала, паузы.

**slatefree** берёт рекордер за эталон времени: находит каждый клип каждой камеры внутри записи рекордера по
накамерному звуку и собирает готовый таймлайн DaVinci Resolve — **каждая камера на своей дорожке**, рекордер внизу.

## Возможности

- **Сотни клипов за один проход.** 161 клип / 90 ГБ / 5,3 ч звука рекордера — около 50 с на 4-ядерном ноутбуке.
- **Точнее кадра** там, где писал рекордер (обычно ±5 мс, затем округление до сетки кадров).
- **Рассчитано на реальные мероприятия:** громкая музыка с повторяющимся битом, гулкие залы, часы камер,
  прыгающие при каждом включении, файлы рекордера, разрезанные по 2 ГБ, невыставленные часы рекордера.
- **Паузы рекордера:** клип выравнивается по звуку пересекающегося клипа другой камеры; если такого нет —
  ставится по таймкоду камеры и помечается.
- **Подсказывает, что проверить:** у каждого клипа статус; сомнительные — с маркером в Resolve и строкой в CSV.
- **Хватает бесплатного DaVinci Resolve.** Ничего не перекодируется, исходники не меняются.

## Быстрый старт (Windows)

1. Скачайте `slatefree-vX.Y.Z-windows-x64.zip` в [Releases](https://github.com/MayVortex/slatefree/releases/latest),
   распакуйте куда угодно. `ffmpeg.exe` должен лежать рядом с `slatefree.exe`. (macOS и Linux — [ниже](#macos).)
2. Разложите съёмку так (имена папок камер — любые; папка рекордера по умолчанию `AUDIO`):

   ```text
   D:\Video\2026-10-04 Свадьба\
       ACAM\     клипы камеры A (.MOV/.MP4/...)
       BCAM\     клипы камеры B            ← камер может быть сколько угодно
       AUDIO\    WAV рекордера как есть с карты (не переименовывать)
   ```

3. **Перетащите папку съёмки на `slatefree.exe`.** В окне — ход работы и итог.
4. В DaVinci Resolve (частота проекта — та, что напечатана в конце):
   **File → Import → Timeline →** `<съёмка>\SYNC\<съёмка>_sync.xml`.

Дорожки: V1, V2… — камеры; A1, A2… — звук камер (связан с видео); последние — рекордер (H4n 4CH: `I` встроенные
микрофоны, `M` входы).

### macOS

1. Один раз установите FFmpeg: `brew install ffmpeg` (Homebrew — <https://brew.sh>).
2. Скачайте `slatefree-vX.Y.Z-macos-universal.tar.gz` (Apple Silicon и Intel), распакуйте двойным щелчком.
3. Программа не подписана сертификатом разработчика Apple, поэтому macOS сначала её блокирует. Разрешите один раз
   в Терминале (после команды перетащите распакованную папку в окно):

   ```bash
   xattr -dr com.apple.quarantine ~/Downloads/slatefree-v1.2.0-macos-universal
   ```

4. **Дважды щёлкните `slatefree.command`**, перетащите папку съёмки в открывшееся окно Терминала, нажмите Enter.
5. Импортируйте `<съёмка>/SYNC/<съёмка>_sync.xml` в DaVinci Resolve, как выше.

### Linux

Установите FFmpeg из пакетов системы (`sudo apt install ffmpeg` и т.п.), распакуйте
`slatefree-vX.Y.Z-linux-x64.tar.gz` и запустите `./slatefree <папка съёмки>`.

## Подготовка к съёмке

Обязательно только два условия: **рекордер пишет непрерывно** и **каждая камера пишет свой звук**.

### Рекордер

- **Включить до начала значимой части и не останавливать.**
- Должен писать **BWF** с меткой времени (`bext` TimeReference) — H4n пишет, большинство современных рекордеров тоже.
  Часы рекордера выставлять **не нужно**.
- Файлы, разрезанные по 2 ГБ, склеиваются встык; несколько отдельных записей — тоже нормально.
- Ставить там, где он слышит то же, что камеры (зал / порталы). H4n в режиме 4CH: по умолчанию для синхронизации
  берутся встроенные микрофоны (`…I.wav`), `--ref-suffix M` — входы.
- **Рекомендуем взять сигнал с пульта двумя раздельными каналами: один — полный микс (музыка + микрофоны),
  второй — только чистые микрофоны** (какой из них левый, а какой правый — не важно). slatefree анализирует сумму каналов, поэтому микс даёт сигнал для синхронизации
  даже когда никто не говорит, а монтажёр потом берёт только канал с чистыми микрофонами — чистая речь без фоновой музыки, которую
  так тяжело аккуратно резать. На H4n писать в режиме 4CH: встроенные микрофоны продолжают писать зал (`…I.wav`),
  пульт попадает в `…M.wav` — на таймлайне это две отдельные дорожки.
- Не переименовывать WAV. Миксы из монтажки пропускаются автоматически, остальное — `--exclude`.

### Камеры

- **Не выключать запись звука в камере** (встроенного микрофона достаточно) — синхронизация идёт по нему.
- **Таймкод: лучше всего Free Run.** Таймкод служит грубыми часами камеры — где искать клип. Таймкод каждого клипа
  сверяется со временем создания файла: клипы, у которых он не ведёт себя как часы (*Rec Run* — считает только время
  записи, или сброс), перечисляются по именам (или помечается вся папка) и ставятся по времени создания файла. Это
  работает, но Free Run надёжнее. (Canon: *Меню → Тайм-код → Отсчёт → Free run*.)
- Часы камер не обязаны совпадать между собой и с рекордером; скачки на секунду при включении не мешают.
  Не менять время и часовой пояс во время мероприятия.
- **Одна частота кадров у основных камер.** Клипы с другой частотой (слоумо 50/60p) пропускаются и перечислены в отчёте.

## Результат и статусы

`<съёмка>\SYNC\`: таймлайн `<съёмка>_sync.xml`, отчёт `sync_result.csv` (разделитель `;`; в колонке `tc_check` —
результат проверки таймкода: `ok` / `bad` / `none`), кэш звука `.cache\`
(ускоряет повторный запуск, потом можно удалить).

| Статус | Значение | Точность |
|---|---|---|
| `ok` | найден в записи рекордера уверенно | ±5 мс + округление до кадра |
| `check` | найден и согласуется с соседями, но совпадение слабое — глянуть | обычно как `ok` |
| `camsync` | рекордер не писал; выровнен по звуку пересекающегося клипа другой камеры | до кадра между камерами |
| `outside-recorder` | рекордер не писал и других камер нет — по таймкоду | ±0,5 с |
| `no-camera-audio`, `not-found`, `model` | по таймкоду камеры | ±0,5 с |

## Ограничения

- **Проверено пока на одном реальном мероприятии:** Canon EOS 5D Mark III (MOV) + Canon EOS R8 (MP4) + Zoom H4n (4CH),
  23,976 к/с, 161 клип за ~6 ч, **DaVinci Resolve 21 (бесплатный), Windows 11**. Другие камеры, рекордеры и версии
  Resolve должны работать, но не проверены — отчёты очень приветствуются.
- Сборки для **macOS и Linux** собираются и проходят тесты в CI, но на реальной съёмке и с DaVinci Resolve под
  macOS/Linux ещё не проверялись — расскажите, как прошло.
- Вывод — **FCP 7 XML для DaVinci Resolve**; Premiere Pro не проверялся; FCPX/AAF нет.
- **Один рекордер** на съёмку.
- **Одна частота таймлайна**; клипы с другой частотой пропускаются. Последовательность пишется как 1920×1080.
- Где снимала одна камера и рекордер не писал — синхронизировать не с чем: по таймкоду ±0,5 с, с маркером.
- Дрейф часов внутри клипа измеряется, но не компенсируется: обычно меньше кадра для клипов до ~15 мин.
- Точность на таймлайне ограничена сеткой кадров (±½ кадра).

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Resolve: *«timecode extents do not match»* | Импортировать в проект, где этих клипов ещё нет в Media Pool, или с исходными, неизменёнными файлами. |
| Камера целиком `unplaced` | У камеры нет звука или она ни разу не пересекается с записью рекордера. |
| Много `check` подряд | Обычно очень тихие или очень шумные места — посмотреть, чаще всего всё верно. |
| *«у ВСЕХ клипов неправильный таймкод»* / *«клипы с неправильным таймкодом»* | Камера была в Rec Run или таймкод сбросился. Синхронизация всё равно работает (по времени файла); на следующую съёмку включите Free Run. |
| Клипы камеры стабильно смещены на секунды | Во время мероприятия меняли часы или часовой пояс камеры. |
| `Не удалось запустить ffmpeg` | Windows: `ffmpeg.exe` рядом с `slatefree.exe`. macOS: `brew install ffmpeg`. Linux: пакет `ffmpeg`. |
| macOS: *«не удаётся проверить разработчика»* | Один раз выполнить команду `xattr -dr com.apple.quarantine …` из раздела [macOS](#macos). |

Ключи командной строки, принцип работы и сборка — в [английском README](README.md#command-line).

## Безопасность и доверие

slatefree читает съёмку и пишет рядом два файла; **в сеть не обращается** и не запускает ничего, кроме **ffmpeg**.
Это проверяется автоматически при каждом изменении: CodeQL (статический анализ безопасности), cargo-deny (известные
уязвимости RustSec/CVE в зависимостях, лицензии, источники, запрет сетевых библиотек), pip-audit и bandit (Python),
линтеры clippy и ruff, отдельная проверка «без сети», Dependabot. Подробности — в
[английском README](README.md#security-and-trust).

**Файлы релизов собирает GitHub Actions из исходников тега** — вручную бинарники никто не загружает. У каждого релиза
есть `SHA256SUMS.txt` и подписанная аттестация сборки; проверить скачанный файл:

```bash
gh attestation verify slatefree-v1.2.0-windows-x64.zip --repo MayVortex/slatefree
```
